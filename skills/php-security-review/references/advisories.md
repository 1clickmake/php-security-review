# 보안 권고 스냅샷 (2026-10-28 기준)

> 이 파일은 **정적 스냅샷**이다. 검수 시점에 최신 정보와 다를 수 있으므로, 아래 "갱신 절차"를 함께 수행한다.
> 스크립트 `scripts/version-check.ps1` 이 PHP·그누보드 버전을 자동 대조한다.

## 1. PHP 코어 — PHP2Shell

| 항목 | 내용 |
|---|---|
| CVE | **CVE-2026-109618**, **CVE-2026-109619** |
| 공개 | 2026-10-21 (일부 정보는 10-17 이전 유출, 실제 악용 선행) |
| 심각도 | CVSS v4.0 **9.2 (Critical)** |
| 유형 | 비인증 원격 코드 실행(RCE), 워커 메모리 노출 |
| 원인 | ① OOM 처리 시 `longjmp()` 로 요청 메모리 미초기화 ② fatal error 후 stale global state |
| 영향 | mod_php, PHP-FPM, php-cgi, FrankenPHP, LiteSpeed — **웹 요청을 처리하는 모든 PHP** |
| 특징 | **애플리케이션 인증/코드로 차단 불가.** PHP가 앱 코드보다 먼저 요청을 처리 |
| 상태 | CISA KEV 등록(2026-10-26), PoC 유통 |

### 조치
1. PHP 버전 확인 (`php -v`, 호스팅 관리자 페이지, `X-Powered-By`, `/install/` 페이지)
2. 위 최소 버전 이상으로 업데이트 (공유호스팅은 업체에 요청)
3. 컨테이너/이미지 사용 시 **재빌드 후 워커 재시작**
4. 업데이트 후 구버전 프로세스가 남아있지 않은지 확인

> 그누보드 소스 업데이트나 관리자 비밀번호 변경으로는 해결되지 않는다.

### 확인 방법
```powershell
powershell -ExecutionPolicy Bypass -File scripts\version-check.ps1 -Path <그누보드루트>
```
→ GitHub 최신 릴리스와 자동 비교.

### 업데이트 시 주의
- **백업 필수** (DB + 파일)
- 테마/스킨 커스텀 수정분은 덮어써질 수 있음 → diff 확인
- 업데이트 후 **관리자 → 환경설정 → DB업그레이드** 필요할 수 있음
- 5.5.x → 5.6.x 는 마이너 업그레이드 절차를 공식 안내대로 따를 것

## 3. 그누보드 구조상 상시 위험 (버전 무관)

| 항목 | 위험 | 조치 |
|---|---|---|
| `install/` 잔존 | 재설치 공격, SQL 덤프 노출 | 삭제 또는 접근 차단 |
| `data/dbconfig.php` 노출 | DB 자격증명 유출 | `data/.htaccess` 또는 서버 deny 확인 |
| `data/` 내 `*.sql`, 백업 | 전체 DB 유출 | 즉시 삭제 |
| `extend/*.php` | 자동 로드 → 백도어 상시 실행 | 파일 목록·출처 확인 |
| `plugin/` 구버전 | 서드파티 취약점 | 사용 중인 것만 최신화 |
| 코어 직접 수정 | 업데이트 시 유실 + 취약점 은폐 | 커스텀은 스킨/`extend` 로 |

## 5. 갱신 절차 (분기 1회 또는 검수 시)

1. PHP: 공식 보안 공지 확인 → 최소 패치 버전표 갱신
2. 그누보드: `https://github.com/gnuboard/gnuboard5/releases` 최신 확인
3. 이 파일 상단 날짜 갱신
4. `scripts/version-check.ps1` 의 `$phpFixed` 해시테이블 갱신
5. 변경 이력을 이 문서 하단에 1줄로 기록
