description: PHP 보안 검수 (php-security-review 스킬 강제 로드)
---
php-security-review 스킬을 로드한 뒤, 다음 대상의 보안 검수를 수행한다: $ARGUMENTS

수행 지시:

1. 대상이 비어 있으면 현재 작업 디렉터리 전체를 검수한다. 그누보드 구조(`lib/`, `bbs/`, `adm/`, `skin/`, `extend/`, `data/`, `install/`)가 보이면 `references/gnuboard.md` 를 먼저 읽고 그 프로필을 우선 적용한다.
2. **가장 먼저 Step 0.5(버전·패치 대조)를 수행한다.** `scripts/version-check.ps1` 을 직접 실행해 PHP 버전과 그누보드 최신 버전을 대조하고, 결과를 보고서 맨 앞 "즉시 조치" 섹션에 둔다. PHP 버전을 모르면 도메인 기반 HTTP 확인을 제안하고, 추측하지 않는다.
3. 이어서 스킬의 워크플로 Step 0~6 을 따른다. 스캐너(`scripts/scan.ps1`)는 네가 직접 PowerShell로 실행한다. 사용자에게 터미널 실행을 요청하지 않는다.
4. 스캐너 결과는 **후보**일 뿐이다. 각 후보의 source → sink 데이터 흐름을 실제 코드로 확인하고, 방어 코드가 싱크 직전에 있는지 판정한다.
5. 판정 결과를 스킬의 보고서 형식으로 한국어로 정리한다: 즉시 조치(버전) → 등급 요약 표 → 항목별(위치 `file:line`, 유형/CWE, 데이터 흐름, 도달 조건, 영향, 재현 시나리오, 패치 코드, 재검증).
6. 근거가 부족한 항목은 "확인 필요" 섹션으로 분리한다. 추측으로 Critical을 올리지 않는다.
7. 코드 수정은 하지 않는다. 패치 코드는 보고서에 제시만 하고, 적용은 사용자가 요청할 때 한다.
8. 그누보드 코어(`lib/`, `bbs/`, `adm/`)는 직접 패치하지 말고 버전 업데이트를 권고한다. `extend/` 의심 파일은 삭제하지 말고 내용을 제시해 확인을 받는다.
9. `references/advisories.md` 는 스냅샷이다. 검수 시점 기준 최신 PHP 보안 공지와 그누보드 릴리스 노트를 웹으로 확인해 차이를 반영한다.
